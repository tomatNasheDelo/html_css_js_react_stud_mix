Вот базовая версия виджета в трёх файлах. Пока он работает без бэкенда:
 ответ оператора имитируется. Вся работа с сервером вынесена в одну 
 функцию `sendToServer`, поэтому позже вы замените её на WebSocket,
  не трогая остальной код.

Структура:
```
widget/
├── index.html
├── style.css
└── widget.js
```

**widget.js**
```javascript
const toggleBtn = document.getElementById('chat-toggle');
const closeBtn  = document.getElementById('chat-close');
const chatWindow = document.getElementById('chat-window');
const messagesEl = document.getElementById('chat-messages');
const form  = document.getElementById('chat-form');
const input = document.getElementById('chat-input');

// Открыть / закрыть окно
toggleBtn.addEventListener('click', () => {
  chatWindow.classList.toggle('hidden');
  if (!chatWindow.classList.contains('hidden')) input.focus();
});
closeBtn.addEventListener('click', () => chatWindow.classList.add('hidden'));

// Добавить сообщение в окно. sender: 'user' или 'operator'
function addMessage(text, sender) {
  const el = document.createElement('div');
  el.className = `message ${sender}`;
  el.textContent = text; // textContent, а не innerHTML — защита от XSS
  messagesEl.appendChild(el);
  messagesEl.scrollTop = messagesEl.scrollHeight;
}

// ВРЕМЕННАЯ ЗАГЛУШКА: сюда позже придёт WebSocket
function sendToServer(text) {
  setTimeout(() => {
    receiveFromServer('Оператор: получил ваше сообщение «' + text + '»');
  }, 800);
}

// Эту функцию позже вызовет ws.onmessage
function receiveFromServer(text) {
  addMessage(text, 'operator');
}

// Отправка формы
form.addEventListener('submit', (e) => {
  e.preventDefault();
  const text = input.value.trim();
  if (!text) return;

  addMessage(text, 'user');
  sendToServer(text);
  input.value = '';
});

// Приветствие
addMessage('Здравствуйте! Чем можем помочь?', 'operator');
```

**Как запустить.** Положите три файла в одну папку и откройте `index.html`
 в браузере. Либо запустите в этой папке `python3 -m http.server 8000` и откройте
  `http://localhost:8000`.

**Как подключится WebSocket позже.** Заглушка заменяется примерно так:
```javascript
const ws = new WebSocket('ws://localhost:8080/chat');
ws.onmessage = (event) => receiveFromServer(event.data);

function sendToServer(text) {
  ws.send(text);
}
```
На стороне Java это будет WebSocket-эндпоинт (например, Spring `TextWebSocketHandler`),
 который принимает сообщение и пересылает его в Telegram-чат оператора через Bot API.
  Ответ оператора идёт обратно по тому же соединению.

Следующий шаг, если хотите: добавить идентификатор сессии посетителя, 
чтобы оператор в Telegram видел, кому именно отвечает, 
и автоматическое переподключение WebSocket при обрыве.
